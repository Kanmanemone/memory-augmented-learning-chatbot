# PRD: memory-augmented-learning-chatbot

## 목표
개인 학습자의 대화를 기억하는 챗봇. 방금 나눈 대화(STM)뿐 아니라 지난 세션에서 뭘 배우고 뭘 어려워했는지(LTM), 특정 주제에 대해 시간이 지나며 실력이 어떻게 변했는지(Episodic)까지 기억해서, 같은 질문을 다시 해도 매번 처음 설명하듯 답하지 않는 학습 도우미를 만든다.

## 사용자
학습 기록을 스스로 관리해줄 개인용 AI 튜터가 필요한 1인 사용자. (지금은 단일 사용자 전용 — 여러 사용자를 구분해서 다루는 기능은 없음)

## 핵심 기능
1. **STM (단기 기억)**: 현재 세션의 대화 원문을 항상 유지하고, 매 응답마다 LLM 컨텍스트에 주입해서 방금 나눈 이야기를 잊지 않는다.
2. **LTM (장기 기억)**: 세션이 끝나면 그 세션에서 배운 내용, 강점, 어려워한 부분을 요약해 저장하고, 다음 세션에서 관련 있을 때 다시 불러온다.
3. **Episodic (주제별 학습 이력)**: 여러 세션에 걸쳐 같은 주제(예: `programming:python-decorators`)에 대한 강점/약점/질문 이력을 누적해서, 같은 주제를 다시 물어보면 이전 맥락을 반영해 답한다.

## MVP 제외 사항
- 멀티유저 지원 (계정 구분, 사용자별 데이터 분리)
- 웹/GUI 인터페이스 (지금은 CLI 또는 Python에서 직접 import해서 쓰는 라이브러리 형태)
- 실제 임베딩 API 연동 (지금은 결정적(deterministic) fallback 벡터를 쓰고 있고, 실 임베딩 도입은 아직 미결정 — [[project-memory-augmented-chatbot-refactor]] 참고)
- 유휴시간/일 단위 배치 승격 스케줄러 (`promote_stm_to_ltm_if_idle` 등 — 제품에 남길지 여부 미결정)
- GDG 워크숍 데모 재현을 위한 하드코딩 로직 (진행 중인 정리 대상)

## 인터페이스
- 지금은 GUI/웹 화면이 없는 프로젝트라 "디자인" 대신 인터페이스 형태를 적는다.
- CLI: `python chatbot.py` 실행 시 터미널에서 대화하는 REPL.
- 라이브러리: `from chatbot import Chatbot`으로 다른 Python 코드에서 직접 사용.
